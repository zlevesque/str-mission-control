    Connect live data

    You keep this dashboard. We only connect your private data.

    Take these steps in order. You are not designing anything, choosing cards, or sharing your account passwords with an AI.

    🔒 Tiny safety rule

    Never put an API key, password, webhook link, guest phone number, door code, or Wi-Fi detail into this page, GitHub, or an AI chat.

    1Make or sign in to CloudflareThis is the private home for your data helper.
    1. Open Cloudflare in a normal browser tab.
    2. Choose Sign up if you are new, or sign in if you already have an account.
    3. Finish any email-verification step Cloudflare asks for.
    4. Stop when you see the Cloudflare dashboard. You do not need to make a random project yet.
    2Let a coding helper do the computer choresIt installs the private helper; it does not rebuild your dashboard.
    1. Open your downloaded str-mission-control folder in Codex, Claude Code, or another coding helper.
    2. Tell it: Open worker/README.md and set up only the worker folder. Do not redesign the dashboard. Stop whenever I need to sign in or enter a secret.
    3. It may run a command that opens Cloudflare in your browser. You sign in and approve the connection there.
    4. Do not paste a Cloudflare password, API key, or secret into the coding chat.
    3Put your private helper onlineCloudflare calls it a Worker. Think of it as a tiny locked receptionist.
    1. Your helper runs npm install inside the worker folder.
    2. When it runs npx wrangler login, Cloudflare opens in your browser. Sign in and approve it yourself.
    3. It runs npx wrangler kv namespace create MISSION_CONTROL. Copy the long ID Cloudflare shows; it is an identifier, not a password.
    4. It replaces REPLACE_WITH_YOUR_KV_NAMESPACE_ID in worker/wrangler.jsonc, then changes the two friendly names for your business and property.
    5. It runs npm run deploy. Copy the new web address ending in workers.dev. This is your private Mission Control address.
    6. Open that address. You should see this same dashboard. Add /health to the end; a small “Worker is running” message means it worked.
    4Make two private access codes in CloudflareThese stay in Cloudflare, never in this form.
    1. Use your password manager to make two different long random strings. Keep both there.
    2. In Cloudflare, go to Workers & Pages, choose your Worker, then choose Settings → Variables and Secrets → Add.
    3. Choose Secret, then add DASHBOARD_ACCESS_TOKEN with your first random string.
    4. Add a second Secret named HOSPITABLE_WEBHOOK_SECRET with your second random string.
    5. Click Deploy or save after each one. Cloudflare will hide the values afterward—that is expected.
    5Tell Hospitable where to send reservationsThis is the one-time “doorbell” connection.
    1. Make this private address in your password manager: YOUR-WORKER-ADDRESS/webhooks/hospitable?key=YOUR_HOSPITABLE_WEBHOOK_SECRET.
    2. In Hospitable, choose Apps → Webhooks, stay on the first Webhooks tab, then click + Add new.
    3. Name it Mission Control, paste that private address, and select Reservations. Add Reviews if you want review-follow-up flags.
    4. Save it. Only use Hospitable’s Test button after checking the address is your own Worker; the test can use real guest information.
    5. Use the webhook’s three-dot menu and choose Send historic webhooks to bring in accepted reservations.

    Open Hospitable’s official webhook instructions if their menus look different.

    6Come back to this form and connectAlmost there—this form needs only your Worker address and access code.
    1. Paste your workers.dev address in the first box on the right.
    2. Paste the value you saved as DASHBOARD_ACCESS_TOKEN in the second box.
    3. Click Connect this dashboard. Your sample stays will be replaced with your protected dashboard data.
    7Optional: add PriceLabs pricingHospitable gives bookings; PriceLabs adds rate context.
    1. In PriceLabs, go to Account Settings → API Details → Enable → I Need API Access.
    2. Type API when it asks, then copy the key.
    3. Back in Cloudflare, add it as a Secret named PRICELABS_API_KEY and deploy the change.
    4. Reconnect this dashboard, click Find my PriceLabs listings, choose your property, then click Use this PriceLabs listing.

    PriceLabs MCP is optional for AI analysis. The private Customer API is what powers the dashboard. Open PriceLabs’ official API instructions.

    This form never asks for Hospitable or PriceLabs API keys.
